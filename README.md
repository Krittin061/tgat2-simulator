# 🎯 TGAT2 Simulator - เว็บแอปพลิเคชันจำลองการสอบเสมือนจริง (การคิดอย่างมีเหตุผล)

เว็บแอปพลิเคชันจำลองสอบเสมือนจริงวิชา **TGAT2 (การคิดอย่างมีเหตุผล - Critical & Logical Reasoning)** พัฒนาด้วย **Next.js (App Router)** ร่วมกับ **Supabase Cloud (PostgreSQL & Object Storage)** ตามเกณฑ์มาตรฐานจริงของ ทปอ. (ที่ประชุมอธิการบดีแห่งประเทศไทย)

---

## 📌 โครงสร้างข้อสอบตามเกณฑ์จริง ทปอ.
- **รูปแบบข้อสอบ**: ปรนัย 5 ตัวเลือก
- **จำนวนข้อ**: 80 ข้อ
- **เวลาในการทำ**: 90 นาที (5,400 วินาที เฉลี่ยประมาณ 67.5 วินาที/ข้อ)
- **คะแนนเต็ม**: 100.00 คะแนน (ข้อละ 1.25 คะแนน)
- **ครอบคลุม 4 ทักษะย่อย และจัดเรียงตรงตามพิมพ์เขียว (Blueprint) 16 หัวข้อย่อย (ด้านละ 4 หัวข้อย่อย หัวข้อย่อยละ 5 ข้อ รวม 80 ข้อ)**:
  1. **ความสามารถทางภาษา (Verbal Reasoning)**: ข้อ 1 - 20 (25 คะแนน)
     - ข้อ 1 - 5: การสื่อความหมาย (ความหมายตรง-นัย, ความกำกวม, บริบทคำ)
     - ข้อ 6 - 10: การใช้ภาษา (ระดับภาษา, ภาษาแบบแผน, คำเชื่อม/บุพบท)
     - ข้อ 11 - 15: การอ่าน (การจับใจความสำคัญ, ตีความสาร, เจตนาผู้เขียน)
     - ข้อ 16 - 20: การเข้าใจสาร (การเติมคำในช่องว่าง, สำนวนไทย, บริบทคำศัพท์)
  2. **ความสามารถทางตัวเลข (Numerical Reasoning)**: ข้อ 21 - 40 (25 คะแนน)
     - ข้อ 21 - 25: อนุกรมมิติ
     - ข้อ 26 - 30: การเปรียบเทียบเชิงปริมาณ (สดมภ์ ก, ข, ค)
     - ข้อ 31 - 35: ความเพียงพอของข้อมูล (Data Sufficiency)
     - ข้อ 36 - 40: โจทย์ปัญหาคณิตศาสตร์ (สมการ, อัตราส่วน, ความน่าจะเป็น)
  3. **ความสามารถทางมิติสัมพันธ์ (Spatial Reasoning)**: ข้อ 41 - 60 (25 คะแนน)
     - ข้อ 41 - 45: การพับกล่อง (คลี่และประกอบลูกบาศก์)
     - ข้อ 46 - 50: รูปทรงเรขาคณิต 3 มิติ (การนับบล็อก, มุมมองภาพตัด)
     - ข้อ 51 - 55: การหมุนภาพสามมิติ
     - ข้อ 56 - 60: การประกอบภาพ
  4. **ความสามารถทางเหตุผล (Logical Reasoning)**: ข้อ 61 - 80 (25 คะแนน)
     - ข้อ 61 - 65: อนุกรมภาพ
     - ข้อ 66 - 70: ความสัมพันธ์ของภาพ (อุปมาอุปไมยภาพ)
     - ข้อ 71 - 75: การวิเคราะห์เงื่อนไขสัญลักษณ์ / ตรรกศาสตร์
     - ข้อ 76 - 80: การวิเคราะห์เงื่อนไขสถานการณ์ / การจัดลำดับตำแหน่ง

## ☁️ สถาปัตยกรรมข้อมูลบน Supabase Cloud

ระบบทำงานโดยเชื่อมต่อกับฐานข้อมูล **Supabase Cloud** แบบ Full-stack โดยตรง:

```text
+-------------------------------------------------------------+
|                       Supabase Cloud                        |
+-------------------------------------------------------------+
|  [public.questions]   อ่านได้สาธารณะ (80 ข้อ, choices JSONB)  |
|  [public.users]       ปิดสาธารณะ — รหัสผ่าน bcrypt           |
|  [public.user_sessions] ปิดสาธารณะ — เก็บ SHA-256 ของ token  |
|  [public.exam_attempts] ปิดสาธารณะ — ผลสอบรายบุคคล           |
|                                                             |
|  ฟังก์ชัน (เรียกด้วย anon key, ตรวจรหัสผ่าน/session เอง):     |
|  register_user, login_user, get_session_user,               |
|  logout_session, save_exam_attempt, list_exam_attempts,     |
|  get_exam_attempt                                           |
+-------------------------------------------------------------+
```

1. **ตาราง `questions`**: โจทย์ภาษาไทยทั้ง 80 ข้อ ช้อยส์ เฉลยละเอียด และพาธรูปภาพ (รูปอยู่ที่ `public/exam_images/` ของแอป)
2. **ตาราง `users`**: บัญชีผู้ใช้ รหัสผ่านแฮชด้วย bcrypt และตัวนับการใส่รหัสผิด
3. **ตาราง `user_sessions`**: session การเข้าสู่ระบบ (แอปเก็บ token ใน cookie แบบ HttpOnly)
4. **ตาราง `exam_attempts`**: ผลสอบของผู้ใช้แต่ละคน ดูได้เฉพาะเจ้าของ
5. โครงสร้างตารางทั้งหมดอยู่ใน `supabase/schema.sql` (มีลำดับการติดตั้งฐานข้อมูลใหม่อยู่ที่หัวไฟล์)

## 🚀 ฟังก์ชันหลักของระบบ

### 1. โหมดสอบเสมือนจริง (Real Exam Mode)
- **ระบบจับเวลานับถอยหลัง 90 นาที**: สีเตือนตามระดับเวลา (ปกติ -> สีส้มเตือนเมื่อเหลือ 10 นาที -> สีแดงกะพริบแจ้งเตือนเมื่อเหลือ 3 นาที)
- **ระบบสุ่มช้อยส์และลำดับข้ออย่างแม่นยำ**: สุ่มช้อยส์ในข้อความทั่วไป แต่คงลำดับตัวเลือก ก-จ สำหรับข้อสอบมิติสัมพันธ์ที่มีตัวเลือกฝังอยู่ในภาพ เพื่อป้องกันการคลาดเคลื่อน
- **ระบบบันทึกความคืบหน้าอัตโนมัติ (Autosave)**: บันทึกคำตอบแบบ Real-time แม้รีเฟรชหน้าจอหรือเปิดใหม่
- **ระบบปักหมุดข้อที่ลังเล (Flagging)**: กดปุ่มหรือคีย์ลัด `F` เพื่อมาร์กข้อที่ต้องการกลับมาทบทวน
- **ระบบส่งข้อสอบอัตโนมัติ (Auto-submit)**: บังคับส่งและตัดเกรดทันทีเมื่อเวลาหมด (00:00)
- **คีย์ลัดแป้นพิมพ์ (Keyboard Shortcuts)**:
  - `1 - 5`: เลือกตัวเลือกข้อ 1 ถึง 5
  - `N` หรือ `ArrowRight`: ข้อถัดไป
  - `P` หรือ `ArrowLeft`: ขอก่อนหน้า
  - `F`: ปักหมุดข้อสอบ

### 2. โหมดฝึกทำข้อสอบ (Practice Mode)
- ไม่จำกัดเวลา เหมาะสำหรับการทบทวนเนื้อหา
- เลือกฝึกซ้อมเฉพาะทักษะหลัก หรือเจาะจงเฉพาะหัวข้อย่อยได้ตามต้องการ (เช่น เน้นเฉพาะสดมภ์ หรือการพับกล่อง)
- ข้อสอบจัดเรียงตามลำดับพิมพ์เขียว 16 หัวข้อย่อย เพื่อการเรียนรู้อย่างเป็นระบบ
- ตรวจคำตอบทันที (Instant Feedback) พร้อมเฉลยละเอียดและวิธีคิดทีละขั้นตอน

### 3. ระบบวิเคราะห์ผลคะแนนและเฉลยละเอียด (Analytics & Review)
- วิเคราะห์จุดแข็ง (Strengths) และจุดที่ควรพัฒนา (Areas for Improvement) แยกตาม 4 ทักษะ
- วิเคราะห์อัตราความเร็วและการบริหารเวลา (วินาที/ข้อ)
- กระดาษเฉลยคำตอบพร้อมตัวกรอง (ข้อที่ตอบถูก, ข้อที่ตอบผิด, ข้อที่ยังไม่ได้ตอบ)

### 4. ระบบสมาชิกและประวัติการสอบ (Authentication & History)
- ระบบลงทะเบียน (Register) และเข้าสู่ระบบ (Login) บันทึกลงในฐานข้อมูล Supabase Cloud
- รหัสผ่านถูกแฮชด้วย bcrypt และตรวจสอบภายในฐานข้อมูลผ่านฟังก์ชัน `register_user` / `login_user` (`supabase/secure_auth.sql`) ตาราง `users` จึงปิดการเข้าถึงจากสาธารณะได้ทั้งหมด
- สามารถเข้าสอบแบบ Guest ได้ทันทีโดยไม่ต้องเข้าสู่ระบบ
- บันทึกประวัติการทำข้อสอบลงฐานข้อมูลอัตโนมัติเมื่อสอบเสร็จ

## 🛠️ วิธีการติดตั้งและรันโปรเจกต์

1. ไปที่โฟลเดอร์โปรเจกต์:
```bash
cd "tgat2-simulator"
```

2. ตรวจสอบการตั้งค่า `.env.local`:
```env
NEXT_PUBLIC_SUPABASE_URL=https://gcdjeudviekotstbujuh.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOi...
```
   - แอปใช้แค่ 2 ค่านี้ ไม่ต้องใช้ service role key
   - ฐานข้อมูลต้องรัน `supabase/secure_auth.sql` แล้วตามด้วย `supabase/sessions_history.sql` (ฟังก์ชันสมัคร/เข้าสู่ระบบ, session แบบ cookie HttpOnly, ประวัติสอบรายบุคคล, ล็อกบัญชี 15 นาทีเมื่อใส่รหัสผ่านผิด 5 ครั้ง และปิดสิทธิ์สาธารณะที่อันตราย)
   - ถ้าติดต่อ Supabase ไม่ได้ ระบบจะใช้ข้อสอบจากไฟล์ในเครื่องและบัญชีสำรองในหน่วยความจำ Server อัตโนมัติ (ไม่ค้าง)
   - หากโปรเจกต์ Supabase ถูกพัก (Free tier พักอัตโนมัติเมื่อไม่มีการใช้งาน) ให้กด Restore ใน Supabase Dashboard

   **แก้ข้อสอบในฐานข้อมูล:** แก้ไฟล์ใน `src/data/questions/` แล้วซิงก์ด้วย service role key (ห้ามใส่ key นี้ในโค้ดหรือ Vercel ของแอป):
   ```bash
   SUPABASE_SERVICE_ROLE_KEY=... node scripts/sync_supabase_questions.mjs
   ```

3. ติดตั้ง Dependencies (ถ้ายังไม่ได้ติดตั้ง):
```bash
npm install
```

4. รัน Dev Server:
```bash
npm run dev
```

5. เปิดเบราว์เซอร์ไปที่:
```text
http://localhost:3000
```

6. ตรวจสอบโค้ดและทดสอบ Build:
```bash
npm run lint
npm run build
```
