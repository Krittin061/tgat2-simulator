# 🎯 TGAT2 Simulator - เว็บแอปพลิเคชันจำลองการสอบเสมือนจริง (การคิดอย่างมีเหตุผล)

เว็บแอปพลิเคชันจำลองสอบเสมือนจริงวิชา **TGAT2 (การคิดอย่างมีเหตุผล - Critical & Logical Reasoning)** พัฒนาด้วย **Next.js (App Router)** ร่วมกับ **Supabase Cloud (PostgreSQL & Object Storage)** ตามเกณฑ์มาตรฐานจริงของ ทปอ. (ที่ประชุมอธิการบดีแห่งประเทศไทย)

---

## 📌 โครงสร้างข้อสอบตามเกณฑ์จริง ทปอ.
- **รูปแบบข้อสอบ**: ปรนัย 5 ตัวเลือก
- **จำนวนข้อ**: 80 ข้อ
- **เวลาในการทำ**: 90 นาที (5,400 วินาที เฉลี่ยประมาณ 67.5 วินาที/ข้อ)
- **คะแนนเต็ม**: 100.00 คะแนน (ข้อละ 1.25 คะแนน)
- **ครอบคลุม 4 ทักษะย่อยตามพิมพ์เขียว (Blueprint) เฉลี่ยด้านละ 20 ข้อ (25 คะแนนเต็ม)**:
  1. **ความสามารถทางภาษา (Verbal Reasoning)**: ข้อ 1 - 20 (20 ข้อ / 25 คะแนน)
  2. **ความสามารถทางตัวเลข (Numerical Reasoning)**: ข้อ 21 - 40 (20 ข้อ / 25 คะแนน)
  3. **ความสามารถทางมิติสัมพันธ์ (Spatial Reasoning)**: ข้อ 41 - 60 (20 ข้อ / 25 คะแนน) *(รูปภาพข้อสอบจริงความละเอียดสูง โฮสต์บน Supabase Storage CDN)*
  4. **ความสามารถทางเหตุผล (Logical Reasoning)**: ข้อ 61 - 80 (20 ข้อ / 25 คะแนน) *(รวมอนุกรมภาพและความสัมพันธ์ของภาพที่มีรูปภาพประกอบบน CDN)*

---

## ☁️ สถาปัตยกรรมข้อมูลบน Supabase Cloud

ระบบทำงานโดยเชื่อมต่อกับฐานข้อมูล **Supabase Cloud** แบบ Full-stack โดยตรง:

```text
+-------------------------------------------------------------+
|                       Supabase Cloud                        |
+-------------------------------------------------------------+
|                                                             |
|  [public.questions]         [storage.objects: exam-images]  |
|  - 80 ข้อสอบฉบับสมบูรณ์     - 30 ภาพโจทย์มิติสัมพันธ์         |
|  - choices (JSONB)          - q41.png - q70.png             |
|  - correct_answer, image    - CDN Public Access             |
|          |                                                  |
|          +--------------------------+                       |
|                                     |                       |
|  [public.users]             [public.exam_attempts]          |
|  - id (UUID PK)             - id (UUID PK)                  |
|  - name, email (UNIQUE)     - user_id (FK -> users.id)      |
|  - password (Hashed/Safe)   - score, accuracy, time_spent   |
|  - role ('student')         - skill_breakdown, user_answers |
|                                                             |
+-------------------------------------------------------------+
```

1. **ตาราง `questions`**: จัดเก็บโจทย์ภาษาไทย UTF-8 ทั้ง 80 ข้อ ช้อยส์ เฉลยละเอียด และลิงก์รูปภาพ
2. **Storage Bucket `exam-images`**: จัดเก็บรูปภาพโจทย์มิติสัมพันธ์ ข้อ 41–70 ดึงผ่าน Public CDN
3. **ตาราง `users`**: จัดเก็บข้อมูลผู้ใช้งานระบบและนักเรียนที่ลงทะเบียน
4. **ตาราง `exam_attempts`**: จัดเก็บบันทึกประวัติการสอบ คะแนนรวม และการวิเคราะห์รายทักษะ

## 🚀 ฟังก์ชันหลักของระบบ

### 1. โหมดสอบเสมือนจริง (Real Exam Mode)
- **ระบบจับเวลานับถอยหลัง 90 นาที**: สีเตือนตามระดับเวลา (ปกติ -> สีส้มเตือนเมื่อเหลือ 10 นาที -> สีแดงกะพริบแจ้งเตือนเมื่อเหลือ 3 นาที)
- **ระบบสุ่มช้อยส์และลำดับข้ออย่างแม่นยำ**: สุ่มช้อยส์ในข้อความทั่วไป แต่คงลำดับตัวเลือก ก-จ สำหรับข้อสอบมิติสัมพันธ์ที่มีตัวเลือกฝังอยู่ในภาพ เพื่อป้องกันการคลาดเคลื่อน
- **ระบบบันทึกความคืบหน้าอัตโนมัติ (Autosave)**: บันทึกคำตอบแบบ Real-time แม้รีเฟรชหน้าจอหรือเปิดใหม่
- **ระบบปักหมุดข้อที่ลังเล (Flagging)**: กดปุ่มหรือคีย์ลัด `F` เพื่อมาร์กข้อที่ต้องการกลับมาทบทวน
- **ระบบส่งข้อสอบอัตโนมัติ (Auto-submit)**: บังคับส่งและตัดเกรดทันทีเมื่อเวลาหมด (00:00)
- **คีย์ลัดแป้นพิมพ์ (Keyboard Shortcuts)**:
  - `1 - 5`: เลือกตัวเลือกข้อ 1 ถึง 5
  - `N` หรือ `ArrowRight`: ข้อถัดไป
  - `P` หรือ `ArrowLeft`: ขอก่อนหน้า
  - `F`: ปักหมุดข้อสอบ

### 2. โหมดฝึกทำข้อสอบ (Practice Mode)
- ไม่จำกัดเวลา เหมาะสำหรับการทบทวนเนื้อหา
- เลือกฝึกซ้อมเฉพาะทักษะที่ต้องการได้ (เช่น เน้นเฉพาะ มิติสัมพันธ์ หรือ ตัวเลข)
- ตรวจคำตอบทันที (Instant Feedback) พร้อมเฉลยละเอียดและวิธีคิดทีละขั้นตอน

### 3. ระบบวิเคราะห์ผลคะแนนและเฉลยละเอียด (Analytics & Review)
- วิเคราะห์จุดแข็ง (Strengths) และจุดที่ควรพัฒนา (Areas for Improvement) แยกตาม 4 ทักษะ
- วิเคราะห์อัตราความเร็วและการบริหารเวลา (วินาที/ข้อ)
- กระดาษเฉลยคำตอบพร้อมตัวกรอง (ข้อที่ตอบถูก, ข้อที่ตอบผิด, ข้อที่ยังไม่ได้ตอบ)

### 4. ระบบสมาชิกและประวัติการสอบ (Authentication & History)
- ระบบลงทะเบียน (Register) และเข้าสู่ระบบ (Login) บันทึกลงในฐานข้อมูล Supabase Cloud
- สามารถเข้าสอบแบบ Guest ได้ทันทีโดยไม่ต้องเข้าสู่ระบบ
- บันทึกประวัติการทำข้อสอบลงฐานข้อมูลอัตโนมัติเมื่อสอบเสร็จ

## 🛠️ วิธีการติดตั้งและรันโปรเจกต์

1. ไปที่โฟลเดอร์โปรเจกต์:
```bash
cd "tgat2-simulator"
```

2. ตรวจสอบการตั้งค่า `.env.local`:
```env
NEXT_PUBLIC_SUPABASE_URL=https://gcdjeudviekotstbujuh.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOi...
```

3. ติดตั้ง Dependencies (ถ้ายังไม่ได้ติดตั้ง):
```bash
npm install
```

4. รัน Dev Server:
```bash
npm run dev
```

5. เปิดเบราว์เซอร์ไปที่:
```text
http://localhost:3000
```

6. ตรวจสอบโค้ดและทดสอบ Build:
```bash
npm run lint
npm run build
```
